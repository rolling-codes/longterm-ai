# ADR 0002 — Phase 2: Durability, Real Providers, CLI, and SQLite Backend

**Date:** 2026-10-13  
**Status:** Accepted  

## Context

Phase 0 + Phase 1 (ADR 0001) established the core guarantees: bounded tool output,
fail-closed policy, honest usage accounting, verified completion, and durable
continuity. ADR 0001 deliberately deferred four actionable items that did not
require external runtime dependencies for the core:

1. Automatic checkpoint resume wired into the run loop.
2. CLI entry point (`longterm verify`, `longterm rebuild`, `longterm run`).
3. Real provider adapters (OpenAI, Anthropic, Gemini) with protocol conformance.
4. SQLite-backed checkpoint store for durable, atomic cross-process persistence.

## Implemented and Tested (Phase 2)

- **Automatic Checkpoint Resume** (`runtime.py`):
  - Added `delete(task_id)` to `CheckpointStore` to safely remove checkpoints upon terminal completion or cancellation.
  - Initialised `self.ckpt_store = CheckpointStore(self.state_dir)` in `Framework.__init__`.
  - Added `resume: bool = False` to `Framework.run()`. When enabled, loads saved checkpoints, restores step counts and tool log entries, restores state machine status, and resumes execution.
  - Per-step atomic saving after every model call.
  - Terminal cleanup: deletes checkpoint on `COMPLETED`, `FAILED`, or `BLOCKED`.
  - Tested in `tests/test_resume.py`.

- **SQLite Checkpoint Backend** (`sqlite_store.py`):
  - `SqliteCheckpointStore`: Drop-in replacement for `CheckpointStore` with identical `save()`, `load()`, `delete()` interface, plus `list_tasks()`.
  - Uses stdlib `sqlite3` only. WAL mode enabled. Full round-trip serialization of JSON fields (`criteria_status`, `tool_log`).
  - Context manager support (`__enter__`, `__exit__`) for deterministic connection lifecycle.
  - Tested in `tests/test_sqlite_store.py`.

- **Real Provider Adapters** (`providers/`):
  - `OpenAIAdapter`: Adapts OpenAI chat completions, formats tools as functions, parses tool calls, maps `usage.prompt_tokens`/`completion_tokens`, and sets `cost_usd=None` per REQ 008.
  - `AnthropicAdapter`: Adapts Anthropic messages API, handles `tool_use` blocks, maps stop reasons.
  - `GeminiAdapter`: Adapts Google Gemini generative model API, function declarations, and usage metadata.
  - Fully tested with `unittest.mock.MagicMock` in `tests/test_providers.py` without requiring SDK installs.

- **CLI Entry Point** (`cli.py`, `__main__.py`):
  - `longterm verify <task_json> <record_json> <state_dir>`: Layer-one handoff verification.
  - `longterm rebuild <task_json> <transcript_json> <record_json> <state_dir> --format neutral|anthropic|openai`: Rebuild request context.
  - `longterm run <task_json> [--state-dir DIR] [--resume]`: Runs tasks using `FakeModel` for CI/scripting.
  - Added `[project.scripts]` entry `longterm = "longterm_ai.cli:main"` to `pyproject.toml`.
  - Tested in `tests/test_cli.py`.

All 115 tests pass on stdlib only with no runtime dependencies.

## Still Deferred

These remain design intent for Phase 3+:
- Retrieval/search engine ("retrieval-first" engine).
- Semantic handoff checker layers 2–3 (requiring live model evaluator).
- Expanded benchmark suite.
